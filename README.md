# VyPER

**VyPER** ($\nu$-HyPER) is the next evolution of [HyPER](https://github.com/tzuhanchang/HyPER), based on the pioneering concept of event reconstruction with hypergraph representation learning.
By combining message-passing with generative diffusion model, VyPER is able to perform full event reconstruction, even the ones with multiple neutrinos in the final-state.
